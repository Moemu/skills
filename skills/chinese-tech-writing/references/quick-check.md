## 完整交付前自检清单

- [ ] 中英文之间有空格，全文空格风格统一
- [ ] 中文全角标点；UI 字符串按软件规范（半角`: ? !` + 空格）
- [ ] 数字半角，千位有千分号，无`降低 N 倍`
- [ ] 无 40 字以上长句；无双重否定；无`一逗到底`
- [ ] 全文用`你`；无`您`（除引用官方固定文案）
- [ ] 无网络流行语、无绝对化用语（最好/最强/唯一）
- [ ] 泛指无性别代词；无歧视性词汇
- [ ] 英文术语首现括注；术语译法全文统一
- [ ] 产品名、商标、键名保持英文未译
- [ ] 标题层级连续合法；标题末尾无点号
- [ ] 段落主题唯一、段首中心句、不超 7 行
- [ ] 文件名小写连词线、无中文、无空格

### 操作步骤与安全提示（STE 思想，中英文通用）

- [ ] 每句一个动作；条件前置、逗号分隔后给命令
- [ ] 步骤直接以动词开头（祈使式），不写"进行/实施 + 名词"
- [ ] 复杂并列信息已垂直列表化；Note 只给信息不带指令
- [ ] 安全提示三段式：警告/注意 + 命令或条件 + 风险后果
- [ ] 警告（WARNING）= 人身风险，注意（CAUTION）= 设备风险，等级无误

### 英文 STE 合规文本（仅在明确要求时）

- [ ] 词汇全部来自 STE 词典批准词或批准的 TN/TV
- [ ] 一词一义、一词一性；同义词只用选定的那一个
- [ ] 动词仅简单时态；无进行/完成时、无助动词堆叠、"-ing" 只作名词或修饰语
- [ ] 复合名词 ≤3 词；无缩略词（do not）；无分号；美式拼写
- [ ] 程序文每句 ≤20 词；描述文每句 ≤25 词、每段 ≤6 句
- [ ] 同一物件/操作全篇同一措辞
