# ASD-STE100 简明技术英语——核心思想提炼

来源：ASD-STE100 Issue 9（2025-01-15，ASD STEMG 出品，433 页）。原标准为受版权保护的付费规范，本文件只提炼其规则体系与理念，**不含原文备份**；需要权威条文时以原版为准。

ASD-STE100（Simplified Technical English，STE）是一种**受控自然语言**和国际标准，最初为航空维修文档而生（1986 年 AECMA 简化英语指南 → 2005 年更名 ASD-STE100），现已被航空航天之外的机械、轨道交通、医疗、IT 等行业以及语言服务、机器翻译与 LLM 领域广泛采用。

## 一、它解决什么问题

技术文档的读者大多以英语为第二语言。英语一词多义、同义词泛滥、句式复杂，会造成误解；在航空领域误解直接威胁生命。STE 的对策是把"作者的自由度"管起来：**用最少的词、最简单的句式、唯一确定的表达，让全世界读者读一遍就懂**。它明确列出的收益之一就是便于翻译：受控的词汇和句式使译者、神经机器翻译和 LLM 的输出更稳定。

STE 明确不管理：排版格式、缩写词表、计量单位（交给各公司/行业的出版规范）。它是配套规范使用的一环，不是孤立标准，也不是英语教学教材。

## 二、两大部分的结构

**Part 1 写作规则**：9 节共 53 条规则。
**Part 2 受控词典**：875 个批准词（approved words）+ 1274 个非批准词及其批准替代词。词典四栏式：词条（词性）｜批准含义/ALTERNATIVES｜STE 例句｜非 STE 例句。大写词条=批准可用，小写=禁止使用、须改写。基于美式英语与 Merriam-Webster 拼写。

**核心词汇观：一词一义、一词一性**。例如 "fall" 只批"因重力下落"这一含义，不批"下降"；同义词只留一个——用 "start"，不用 "begin/commence/initiate"。"D"（D 开头大写）的批准词是核心词汇；领域专属词走"技术名词/技术动词"通道（见下）。

## 三、九节规则速览（释义转述）

### 第 1 节 Words（词，规则 1.1–1.14）

- 1.1 只用三类词：词典批准词、技术名词、技术动词。
- 1.2 批准词只作词典指定的词性使用。
- 1.3 批准词只用其批准含义。
- 1.4 动词/形容词只用批准形式（词典给什么形式用什么形式）。
- 1.5–1.6 **技术名词（TN）**制度：词典外词汇只有作为技术名词（或其一部分）才可用；技术名词须是公司/行业/学科批准的词，选词要短、易懂，禁止俚语行话，同一物件禁止多个叫法。附录给出 22 个技术名词类别示例（部件、工具、环境条件、颜色、损伤、计算机、法律法规等）。
- 1.7 技术名词不得当动词用。
- 1.12–1.13 **技术动词（TV）**制度：词典外动词只有属于批准的技术动词类别（制造工艺、计算机操作、法律法规等）才可用，同样不得当名词用。
- 1.14 美式拼写（有官方指令另行要求时除外；引用原文保持原样）。

### 第 2 节 Multi-word nouns（复合名词，规则 2.1–2.2）

- 复合名词最多 3 个词。
- 超过 3 词的技术名词：先写全称，再用两种方法缩短——给出缩略形式，或对作为整体使用的词组加连字符。

### 第 3 节 Verbs（动词，规则 3.1–3.7）

- 3.1 只用词典给出的动词形式。
- 3.2 只允许这些时态/形式：不定式、祈使式、一般现在时、一般过去时、一般将来时、过去分词（仅作形容词用）。禁止进行时、完成时等复杂时态。
- 3.3 过去分词只作形容词。
- 3.4 禁止用助动词构造复杂动词结构（不用 will be + ing、has been + done 之类）。
- 3.5 "-ing" 形式只作技术名词或技术名词中的修饰语（"the operating lever" 可以，"is operating" 不行）。
- 3.6 **主动语态**；只有描述文中施动者未知时才允许被动。
- 3.7 用动词描述动作，不名词化（"to inspect" 而非 "carry out an inspection of"）。

### 第 4 节 Sentences（句子，规则 4.1–4.5）

- 4.1 短句、清晰句。程序文中直接用祈使句下指令；描述文一句一个主题，然后逐句展开。禁止抽象表述（"No leaks are permitted" 不合格，须写成 "Make sure that there are no leaks"）。
- 4.2 **不许省词、不许缩写**（don't → do not；不许省略主语、动词、冠词——省冠词会歧义）。句子短靠拆句，不靠删词。
- 4.3 复杂内容（多物件、多动作、多文档）改用**垂直列表**：引导句以冒号结尾，每项编号（数字、字母、破折号等），列表项尽量短。
- 4.4 用批准的连接词/连接短语衔接相关句子（如 and、or、but、if…then、when）。
- 4.5 名词前按需加冠词（the/a/an）或指示词（this/these），避免歧义。

### 第 5 节 Procedural writing（程序文/操作步骤，规则 5.1–5.5）

- 5.1 **每句最多 20 词**。
- 5.2 每句只写一条指令；仅当多个动作同时发生时才可合并。
- 5.3 指令用祈使句（命令式）。
- 5.4 若读者须先知道某个条件，以描述句开头、逗号隔开命令："Before you X, do Y."（条件在前，动作在后）。
- 5.5 Note 只用于给信息，**不得夹带指令**。

### 第 6 节 Descriptive writing（描述文，规则 6.1–6.6）

- 6.1 信息逐层给出（gradually），不要一次倾倒。
- 6.2 用关键词/关键短语给文本搭逻辑骨架。
- 6.3 **每句最多 25 词**。
- 6.4 用段落归组相关信息。
- 6.5 每段只谈一个主题。
- 6.6 **每段最多 6 句**。

### 第 7 节 Safety instructions（安全指令，规则 7.1–7.3）

- 7.1 按风险等级选用标识词：**WARNING = 有人员伤亡风险；CAUTION = 有设备/物品损坏风险**；两种风险并存时升格为 WARNING。选错等级是典型错误（如氧气管清洁剂案例：看似 caution，实际是爆炸伤亡风险，必须 warning）。其他行业可用 danger/notice 等词或 ISO 3864/ANSI Z535 符号，但结构仍须遵守 7.1–7.3。
- 7.2 安全指令以清晰的命令或条件开头。
- 7.3 随后说明风险或后果——读者知道"为什么会受伤/损坏"才会真正重视。
- 三段式：**标识词 + 命令/条件 + 风险解释**。

### 第 8 节 Punctuation and word count（标点与词数，规则 8.1–8.7）

- 8.1 可用全部标准英语标点，**但禁用分号**。
- 8.2 连字符连接直接相关的词（也影响词数统计，见 8.7）。
- 8.3 括号仅用于图示/正文引用等限 定用途，不得把核心信息塞进括号。
- 8.4 垂直列表中冒号等同句号，结束一个句子（词数以此结算）。
- 8.5 括号内文字在词数中算 1 个词。
- 8.6 以下各按 1 词计：数字、数字+单位、缩写、字母数字编号、引文、标题/标牌/标签文字、人名与组织地名等专有名词。
- 8.7 连字符复合词算 1 词。

### 第 9 节 Writing practices（写作实践，规则 9.1–9.4）+ 通用建议 GR-1..GR-8

- 9.1 逐词替换无法达意时，换句式重写，而不是硬替。
- 9.2 每个批准词都按词典批准的用法用。
- 9.3 不自造短语动词（把两个词拼在一起当动词）。
- 9.4 **术语与措辞风格一致**：同一操作、同一物件永远用同一说法（同一物件一会儿叫 main body、一会儿叫 body assembly 是典型错误）。

通用建议（非强制，防常见错误）：
- **GR-1** 多写连接词 that（"Make sure that…"），帮助读者和翻译引擎看清从句边界。
- **GR-2** 警惕介词 with 的歧义（"Install the panel with the green fasteners" 三种读法）；条件用 with 表达时改为条件从句；工具/手段用 "动词 + with + 工具" 结构让主动词前置。
- **GR-3** 代词指代不清时还原为名词。
- **GR-4** 指示代词 this 必须指代明确。
- **GR-5** 当心假朋友（false friends）：外形相同、含义不同的跨语言词。
- **GR-6** 不用拉丁缩写（e.g./i.e./etc.），写成 for example、that is、and so on 或直接省略。
- **GR-7** 包容性语言：性别代词 he/she 不在批准词内，用中性表达。
- **GR-8** 所有格（'s）可用但谨慎，拿不准就改写。

## 四、把 STE 思想迁移到简体中文技术写作

STE 管的是英语，但其约束思想与中文规范同构，翻译 STE 文本或写安全关键文档时按此执行：

1. **术语唯一**：一个物件全篇一个中文名；一个动词概念全篇一个译法（STE 的"一词一义"对应中文"术语表驱动"）。翻译受控英语时，同一英文批准词永远译同一个中文词。
2. **量化句长**：STE 程序文 ≤20 词、描述文 ≤25 词、段落 ≤6 句——中文操作步骤的对应硬约束是每步一句话一个动作（阮一峰的"20 字内"是其同构物），宁可拆步骤也不写复合指令。
3. **步骤祈使化**：中文操作步骤直接以动词开头（"卸下盖板"），条件前置用逗号分隔（"拆卸盖板前，先断开电源"）——与规则 5.3/5.4 完全对应。
4. **Note 只给信息**：中文"注"不得夹带指令；带指令的用编号步骤。
5. **安全提示三段式**：【警告/注意】+ 命令或条件 + 风险后果说明；**警告=人身伤害，注意=设备损坏**，等级选错比不写更糟。
6. **禁词映射**：STE 禁缩写（do not）、禁名词化、禁自造短语动词 → 中文对应"不写文言压缩句、不用'进行/实施 + 名词'句式（用'进行检查'不如'检查'）、不生造'×化'动词"。
7. **拆句不删词**：中文省略主语是常态，但技术步骤中该有的宾语、量词不能省（STE 规则 4.2 的中文对应）。
8. **垂直列表**：中文技术文档同样适用——复杂并列信息列表化，引导句以冒号结尾，每项编号。

## 五、适用与裁剪

- 明确要求 STE 合规的场景（航空/军工/机械维护文档、需机翻或 LLM 流水线处理的英文源文）：Part 1 的 53 条规则全量执行，术语走公司 TN/TV 词表。
- 未要求 STE 的普通中文技术文档：不机械套用英语词表，但第三、四节的量化约束与结构思想（短句、术语唯一、安全三段式、一 步一动作）始终适用。
- STE 与本技能其余规范冲突时：英文 STE 合规文本以 STE 为准；中文文本以阮一峰/微软规范为准，STE 取其精神。
